# Pure Weibo

Following, not recommended.

适用于微博网页端的油猴脚本：默认进入最新关注微博，清理推荐、热搜和已识别的广告，保留主动搜索与日常互动。

## 功能

- 首页进入“最新微博”，保留关注者原创、转发和自定义分组。
- 过滤关注流中明确的未关注作者、推荐及“赞过”动态。
- 隐藏热搜、推荐关注，以及顶栏的推荐、视频发现和游戏入口。
- 清理视频相关推荐，关闭对应的推荐连播，保留稍后观看队列。
- 保留搜索、个人主页、消息、评论和发微博功能。

支持微博桌面主站、搜索页和独立视频页，不适用于手机网页版。

## 安装

前提条件：准备好 Tampermonkey 或 Violentmonkey 扩展。

### 一键安装

[安装 Pure Weibo (Github)](https://raw.githubusercontent.com/squarezhong/pure-weibo/main/pure-weibo.user.js)

后续可自动获取更新。

### 手动安装

在扩展中新建脚本，将 [pure-weibo.user.js](pure-weibo.user.js) 的全部内容复制进去，替换默认模板并保存；也可通过扩展的本地文件导入功能安装。后续更新需手动替换脚本。

---

安装完成后刷新微博页面即可使用。

## 设置

在油猴菜单中打开 **Pure Weibo：设置**，可调整首页跳转、各项过滤规则和导航入口。页面上没有常驻设置按钮。

修改后点击“保存”生效；取消、Esc 或点击弹窗外部均不保存。“恢复默认”也需要点击保存才生效。页面清理未及时生效时，可使用菜单中的“重新应用规则”。

## 使用说明

无法确认来源的微博会保留，普通正文提到“广告”“推荐”等词不会因此被隐藏。微博改版可能影响过滤效果；如遇误判，可在设置中关闭对应规则。
